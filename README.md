# T.C. Sağlık Bakanlığı
## Cam Buğusu, Görüş Keskinliği ve Ani Körlük Önleme Genel Müdürlüğü

> Bu depo bir şaka değildir. Bu depo bir teşhistir. Bu depo bir epikrizdir.

Gözlüğün bir fırına, çayhaneye, otobüse veya kış sokağına girer girmez ani buğulanması bireysel bir buhar olayı değildir.  
Bu olay **milli netlik kaybı**, **görüş keskinliği krizi** ve **halk sağlığı acilidir**.

Bakanlığımız, buğu tabakasını resmi lezyon, camı muayenehane,  
«Biraz nefes alınca geçer» cümlesini ise **yanlış tedavi ve ihmali müdahale** kabul eder.

## Yürürlük

```bash
python3 gozluk_bugusu.py
```

Program sizden ortam sıcaklığını, çay buharı yoğunluğunu ve buğunun kaçıncı saniyede geldiğini ister.  
Ardından resmi epikriz, görüş kaybı katsayısı ve sevk belgesi üretir.  
Çıktı gerçekten çalışır. Gözlüğünüz buğulanmasa bile Bakanlık buğulandığını varsayar.

## Temel Kavramlar

| Nesne | Resmi statü |
|---|---|
| Gözlük camı | Muayenehane |
| Buğu tabakası | Lezyon / plak |
| Çay buharı | Bulaşıcı ajan |
| Etek ucu / t-shirt | Acil silme protokolü |
| «Biraz bekleyeyim» | Tedavi reddi dilekçesi |
| Lens kullananlar | Risk grubu |

## Sık Sorulan Resmi Cevaplar

**S:** Gerçekten çalışıyor mu?  
**C:** Evet. `python3 gozluk_bugusu.py` yazın. Bakanlık sizi sevk eder, etmez, yine de epikriz basar.

**S:** Copilot ile konuştunuz mu?  
**C:** Copilot'a «gözlük buğulanınca sağlık raporu çıkar mı» diye sorduk. Cevap verdi. Cevabı reçeteye işlenemez bulundu. Camı silmedi.

**S:** Patates var mı?  
**C:** Yok. Yönerge açık. Buğu patates buharı değildir.
